# Tickets — Log4Shell CTF

Учебный уязвимый веб-сервис техподдержки «TechSupport Pro» на Spring Boot. Пользователи создают обращения (тикеты), администратор отвечает.

> ⚠️ Приложение намеренно уязвимо. Запускайте только в изолированной среде, не выставляйте в интернет.

## Запуск

```bash
docker compose up -d --build
```

- Приложение: http://localhost:8080
- Флаг можно задать своим: `FLAG='errypie{...}' docker compose up -d --build` (по умолчанию — плейсхолдер).

Остановить:

```bash
docker compose down
```

## Задание

Цель — получить флаг. Путь (вектор):

1. Найти и проэксплуатировать уязвимость в обработке обращений, получить **RCE**.
2. С помощью RCE выгрузить артефакт приложения с сервера.
3. Проанализировать (декомпилировать) артефакт и найти учётные данные администратора.
4. Войти в админ-панель и найти флаг в одном из обращений.

Формат флага: `errypie{...}`.

## Стек

- Java 11, Spring Boot 2.6.1, Thymeleaf
- Данные хранятся в памяти приложения (без БД)

## Структура репозитория

```
Dockerfile, docker-compose.yml   запуск стенда
prebuilt/tickets.jar             собранный артефакт приложения
```

Исходный код намеренно не включён — его восстановление является частью задания.
